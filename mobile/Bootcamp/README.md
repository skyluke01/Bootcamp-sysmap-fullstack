# Bootcamp Mobile

Aplicação mobile desenvolvida em React Native para gerenciamento de atividades esportivas.

## Tecnologias utilizadas

- React Native
- TypeScript
- React Navigation
- Axios
- AsyncStorage
- React Native Maps
- React Native Image Picker
- React Native Geolocation
- React Native DateTime Picker
- Phosphor React Native

---

## Funcionalidades

### Autenticação
- Cadastro de usuário
- Login
- Persistência da sessão

### Perfil
- Visualização de perfil
- Atualização de dados
- Alteração de foto
- Definição de preferências

### Atividades
- Criar atividade
- Editar atividade
- Cancelar atividade
- Visualizar detalhes da atividade
- Definir localização pelo mapa
- Escolher categoria
- Selecionar imagem da atividade
- Definir atividade pública ou privada

### Participação
- Solicitar participação
- Aprovar ou negar participantes
- Sair da atividade
- Confirmar presença através de código

### Encerramento
- Finalizar atividade
- Visualização de atividade finalizada

---

## Pré-requisitos

Antes de executar o projeto, é necessário possuir:

- Node.js
- npm
- Android Studio
- JDK 17
- Android SDK
- Gradle (via Android Studio)

---

## Instalação

Clone o repositório e entre na pasta do projeto:

```bash
cd mobile/Bootcamp
```

Instale as dependências:

```bash
npm install
```

Execute  Android, já vai iniciar o metro junto (Lembra de abrir o emulador antes):

```bash
npm run-android
```
